# Current product scope

MobileHarness 在 Apple 原生应用中连接感知、Agent 决策与执行，目前以 iPhone 为宿主。本文件说明当前用户范围；模块技术细节见 [Architecture](Architecture.md) 和源码 README。

## 用户场景

| 场景 | 当前范围 |
| --- | --- |
| 语音对话 | 用户启停聆听，查看识别/回复字幕并接收语音输出；使用实际配置且可用的提供者。 |
| 视觉感知 | 前台相机和姿态展示，与语音就绪状态分别管理。 |
| 拍照与录像 | 独立 Camera 窗口提供照片／视频、倒计时取消、闪光灯、变焦、有声录像与限时停止；视频可保存到 App 相册、回放、导出或忽略。录制暂停聆听，后台停止；原生设备效果独立验收。 |
| 表达反馈 | 眼睛、视线、聆听/播放状态和实际音频反馈。 |
| 外接设备 | 发现、连接支持的设备，执行明确授权的有限操作并展示真实结果。 |
| 模型与服务配置 | 选择已支持的本地能力或显式配置云端聊天，管理资源并展示配置/加载失败。 |
| Agent 记录 | 当前提供 Assistant 会话、请求与 Task 来源；运行诊断保留 Action/Task/Agent 状态。记录读取不重放行为。 |
| 诊断 | 用户显式运行支持的诊断；替身、静态预览和实际模型/设备证据分别说明。 |

## 行为与数据边界

用户关闭、原生中断和会话替换会触发所属工作的取消与清理，迟到结果不能覆盖新会话。错误、缺失能力和容量耗尽明确展示；用户可读文案与开发诊断的统一仍在 [架构改进需求](requirements/technical/Core-Architecture-Improvement-Plan.md) 跟进。

页面导航和本地交互直接由 UI/宿主管理，根级任务不随页面消失。Agent 发起的语音、界面与设备效果经过其获准的函数和实际作用域验证。

配置和已提交会话记录可以持久保存，原生音频与运行时状态有各自临时生命周期。照片分析附件与保留原图区分处理；读取媒体或存储历史不等于已提供独立用户相册。业务记录、提交和恢复语义由 [Storage](../MobileHarness/Storage/README.md) 定义。

云端聊天是明确配置的选择，凭据保留在设备本地。原始用户媒体、模型权重与本地签名配置不属于仓库内容。

## 未交付范围与验收

用户相册、日记式记忆、Resource 状态接入和自主构图/运镜等按 [需求索引](requirements/README.md) 维护。通用跨平台、任意系统/第三方 App 控制和不受系统调度限制的后台自治不属于当前交付范围。

[Roadmap](Roadmap.md#acceptance-work) 和 [验证索引](validation/README.md) 区分代码实现、构建、模型测试、原生界面与物理设备验收。本文不把历史演示或有限试验提升为完整质量、延迟或安全结论。

通用灵动岛同时支持App内图标/实际回复频谱及ActivityKit系统摘要。前台目标任务以目标图标和目标文字自动展开、结束收回，其他状态保持紧凑；组件提供统一内容/详情接口并拥有动画。系统呈现由iOS决定，不能强制前台常驻系统岛；系统失败不影响App组件。设备控制仍在Camera窗口，系统不承载实时频谱或扩展后台设备运行。

内容接口重构采用primary/secondary指标与可选detail(text,thumbnail)：有效详情默认展开，手动收起保留内容；优先级整体切换活动并保存各自展示偏好。缩略图本轮仅App内有界显示，系统保留图标/文字。交互与动效由UI组件统一拥有；见[实施计划](requirements/Face-Window-Island-Plan.md)。

## 网页与交互图形

Assistant 可加载网页浏览 Skill 访问HTTP/HTTPS页面、提取文字、逐屏查看截图，并控制窗口。绘图 Skill 接受自然语言任务，由独立模型上下文开发本地HTML/CSS/JS，支持已有项目的局部修改、渲染、重开与删除。源码保存在受控工作区，生成代码不经过主助手输出协议；图像分析受当前模型能力约束。容量、脚本/网络边界及真实验收范围见[Web设计](../MobileHarness/Actions/Web/README.md)与[验证记录](validation/WebKit-Actions.md)。
