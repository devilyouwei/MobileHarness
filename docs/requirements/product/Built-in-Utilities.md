# 预置基础小工具

2026-11-26 记录，待实现。

在 App 中预置类似操作系统自带的轻量小工具。用户可通过手动点击打开对应窗口，并直接完成常用操作。首批范围包括以下三项。

| 工具 | 用户能力 |
| --- | --- |
| 记事本 | 新建、查看、编辑并保存笔记。用户可以直接键入，也可以边说边记，再把内容梳理、修正为笔记。使用 Assistant 整理时，用户可在记事本窗口查看并修改整理稿，确认后保存。 |
| 闹钟 | 查看已设置的闹钟和运行中的倒计时，通过窗口手动设置、查询和取消。提醒行为和 Assistant 操作沿用[闹钟与倒计时需求](Alarms-and-Timers.md)。 |
| 时钟 | 打开独立窗口查看设备当前时间，按设备时区显示。 |

小工具复用现有 [Window 组件](../../../MobileHarness/UI/Components/Window/README.md)。用户主动进入 App 页面以及 Assistant 唤起交互的方式遵守[用户导航与 AI 交互边界](../Manual-Navigation-and-Agent-Interaction.md)。记事本保存用户明确记录的内容，自动生成的日记式记忆另见[用户记忆需求](User-Album-Memory-Plan.md#2-用户记忆)。

## 验收条件

- 手动打开三个工具窗口，分别验证笔记编辑保存、闹钟与倒计时管理、当前时间显示。
- 口述一段想法，让 Assistant 整理成稿，在窗口中修正并确认保存。关闭后重新打开，显示最终确认的版本。
- 在窗口设置后由 Assistant 查询，或由 Assistant 设置后在窗口取消。两种入口读取同一组系统记录，到期提醒按闹钟专项验收。
