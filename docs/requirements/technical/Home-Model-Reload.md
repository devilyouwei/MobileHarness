# 首页模型加载与设置生效

首页进入时检查当前配置启用的 Assistant、Writer、Decision、视觉和语音模型。按实际资源 ID 去重。仅准备未就绪资源，未安装的配置项保留对应失败信息。ModelKit 提供资源身份、状态、加载、普通卸载和取消并卸载的接口。

- 设置保存后按生效变化使相关资源失效。模型更换包含旧选择和新选择，VAD 参数、关键词阈值和合成音色使相应模型失效。有效 App 语言变化使 ASR、TTS 和使用语言提示词的智能体配置失效。下载源等偏好不触发卸载。
- 先关闭相关任务入口，取消旧工作并等待资源释放。模型卸载围栏期间禁止新租约。配置快照由各设置服务持有，语音采集及诊断会话从最新快照创建。首页加载检查需与配置变更串行，任务版本隔离迟到呈现。
- 首页准备统一管理所有已启用的模型，包括增强、关键词和结束确认。Toast 复用顶部提示空间，显示「正在加载 %@…」，覆盖直到模型可用。眼睛动画继续使用原有状态和渲染。失败继续使用现有错误和重试入口。
- 更新 ModelKit、App、Agents、Actions 和 UI 的实现说明。工程回归覆盖实际模型标识、去重、取消式卸载、设置影响范围及加载状态。真机效果单列验证。
