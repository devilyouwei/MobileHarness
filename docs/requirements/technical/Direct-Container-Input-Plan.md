# 外部输入直连 Container

## 状态与基线

代码迁移已实现，自动化、原生 UI 和真机／性能验收分别跟踪。分支 `codex/direct-container-input` 从当前 container 化成果 `197c53d7` 创建；当时工作区干净。未创建新源码目录、顶层模块、第三方依赖或新的持久化格式。

## 需求实现

- ✅ AgentBindings、ActionBindings 目标已合并入 Agents、Actions；Package、Xcode、测试及 imports 同步。四基础模块及 AgentCore 保持独立，Gateway 不再依赖 PlatformKit。
- ✅ UI 子容器拥有本地类型化请求与终态回执。单消费者、最多 64 个普通未终态请求；独立单槽控制入口，取消／停止不等待普通业务 FIFO。根代际、页面取消、消费者退出和迟到回执有明确结果。
- ✅ VisionPerception、SpeechPerception 直接处理原生帧。保留最新视频、原生 64 包有序 PCM、采集围栏、显式溢出和消费方格式转换；不通过 Gateway 传递原始帧。
- ✅ 直接观察相机、设备、资源与故障。资源使用有界变更通知，移除定时编码／比较；State 仍仅持有有限公开事实和唯一拥有者 Writer。
- ✅ Signal 只承担 Agent 通信、执行反馈、回执和轮次结果。ProcessingContext 保留本地因果／代际，所有用户和模型业务操作仍经受保护的 Gateway → Actions 执行。
- ✅ 删除外部接纳接口、适配器、动态订阅、来源列表、旧 schema 与无职责转发。保留真正的角色执行会话、结果关联和取消加入职责；原生错误分类归 Agents Support。

## 验收条件

- ✅ 添加请求不可用／重复消费者／满载／接纳和完成分离／取消／旧代际／消费者关闭回归；控制请求可在普通请求未完成时执行。
- ✅ 原生广播／溢出／采集围栏、只读相机订阅、PCM 序号和布局回归；授权、租约、取消、旧 owner 及真实结果沿用实际业务回归。
- ✅ 总体设计、所属 README、架构决定和边界检查已按当前实现同步；原始 Word 及历史验证记录保留。
- ✅ 已完成完整自动检查、原生窗口测试及四个模拟器构建目标；各次实际结果与本次整理的复核见[验证记录](../../validation/Direct-Container-Input.md)。原生窗口测试不替代 iPhone 实时预览验收。
- ❌ 真机完整业务与生命周期验收：语音、摄影及保存／忽略、跟踪、设置／历史／资源、诊断；权限拒绝、前后台、导航、切镜头、半双工与清理失败。
- ❌ 同设备同配置性能对照：输入到处理 p50/p95、CPU、分配、常驻／峰值内存、丢帧及 PCM 溢出，区分原生采集与真实模型。尚无实测提升幅度。

验收是本需求的一部分，以上缺口关闭前不迁入 completed。架构决定见 [ADR 0218](../../adr/0218-direct-container-input.md)。

## UI 接纳归属补充

用户要求 UI 作为 Container 显式注入 Agent，由实际角色直接监听和解释事件。删除 AgentApplication 的订阅/handleSettings/handleResources/handleHistory 及输入向 ExecutionSession 转交的路径。普通/控制回执、权限、真实结果与取消加入继续成立。✅ 已实现构造注入及 Agent 自有订阅／处理／回执；专项回归覆盖实际 UI 容器和五个负责角色。完整检查、原生编译及原有真机验收缺口分别记录于验证文档。

## 原生输入归属补充

✅ 已实现：清除语音协调器持流、每包 MainActor observe 回调及检测宿主逐帧转交；SpeechPerception 构造注入只读采集能力，直接消费唯一有界原生 PCM 源。原生输入文件归 SpeechPerception／VisionPerception 角色目录，保留动作控制、采集代际、半双工、清理加入和真实失败。

## 语音执行归属收敛

✅ 已实现：语音与感知呈现的执行归属收尾：将语音协调器、音频检测硬件操作和频谱展示归入 Actions，Agent 仅消费输入、运行模型、选择策略和输出受保护调用。保留真实执行服务，不创建换名输入转发层。
