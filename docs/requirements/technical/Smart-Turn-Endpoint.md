# Smart Turn 语句结束确认

在能量或 Silero VAD 达到静音端点时，由可选 Smart Turn v3.2 Core ML 判断语句是否已经说完。设置的「语音活动检测」之后新增「语句结束确认」，默认关闭。使用现有模型管理下载固定 Hugging Face revision 的编译制品，安装后预热，使用前先选择该模型。

- ModelKit 的 VAD 目录容纳独立的端点确认接口和 Core ML 适配。输入为当前语句最近 8 秒的 16 kHz 单声道 Float32 PCM，左侧补零，`probability > 0.5` 接受结束。ModelKit 的管理、模型目录和语音端口负责安装、预热、租约和选择，向 Agents 只暴露概率或未就绪。
- SpeechPerception 在同一条有序 PCM 消费链上确认 VAD 端点，维持当前 ASR 与语句身份。低分之后若恢复说话则先补交停顿音频。每段静音只推理一次，连续静音达到约 2 秒则直接收尾。关闭、未安装、未预热和推理失败时按原 VAD 端点收尾，推理失败记录原操作错误。空转写保护、显式停采集和内部 ASR 分段维持各自的结束语义。端点缓冲限于最近 8 秒，取消或重置时清空。
- Settings 和 Actions 通过现有按能力的模型选项、偏好和下载列表呈现端点确认，删除制品后恢复关闭。更新 ModelKit、语音能力、SpeechPerception、Actions、UI 和总体设计说明。Swift 回归覆盖延后收尾、恢复说话、最长等待、每段静音只调用一次、异常回退及设置和模型目录接入。
- 扩展资源 Gateway 的语音偏好参数，按已有模型选项的能力数限制映射项，保留字节限制。覆盖六项偏好经过 Gateway 保存、重新绑定及删除模型后的恢复。
- 修复语音设置再次保存时的 `invalid payload`。ApplicationControl 的资源意图删除独立的五项限制，并保留字段和消息字节边界。Actions 按 ModelKit 的能力目录验证完整偏好。通过真实 UI 请求入口恢复完整映射，再修改并提交一个模型选项，验证其余设置和模型绑定。
