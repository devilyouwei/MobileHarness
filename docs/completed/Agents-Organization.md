# Agents 角色归属与共享机制整理

## 目标与边界

Agents 拥有输入接纳、私有业务状态、策略、模型决策及角色协作；Actions 拥有真实业务执行，Gateway 保持授权与调度，基础模块保持独立。保留七个角色和编译目标，不新增目录层级。

## 交付项

- ✅ 将具体应用装配和通信目录放到 Agents 根级，Support 只保留跨角色机制。
- ✅ 角色各自解释固定任务载荷，共享机制只负责身份／scope／元数据校验。
- ✅ Assistant 私有会话控制通过角色钩子接入通用 Chat，取消／中断语义不变。
- ✅ 按职责集中内部函数目录、策略和类型，明确语音诊断注册与会话、播放失败适配的所有者。
- ✅ 同步 README、全仓引用、边界检查、Xcode 导航和行为回归。

## 验收

运行 scripts/check.sh；完整 Xcode 可用时运行 scripts/build-ios.sh，遇到环境阻碍保留原失败与替代验证范围。验证旧会话控制准入、固定任务权限和载荷边界、原始执行结果及取消加入，自动化和编译不替代真实模型／设备验收。
