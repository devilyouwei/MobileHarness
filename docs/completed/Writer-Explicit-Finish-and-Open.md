# Writer 显式结束委托与通用作品打开

- Writer 在作品库和编辑工作区使用同一个显式 finish 命令。控制模型只返回正文时，运行时在既有恢复预算内要求补交工具调用。成功、拒绝和发布沿用现有校验及终态回执，工作区文件内容请求继续使用纯文本。
- 删除 openAll。模型先按需查询作品目录，再对自己选中的 taskID 调用 open，可在同一轮提交最多八个独立调用，宿主按顺序执行并记录逐项结果。open 只展示作品，留在作品库域。只有 enter/create 绑定编辑工作区。保留现有作品身份与历史详情读取。
- 同步 Writer Agent 和 Skills、Artifacts 工具说明、模型测试脚本与仓库技术说明。覆盖多开、失败后的后续调用、显式 finish 和纯文本恢复，不改现有 ID 命名。

实施日期为 2026-11-09。检查结果见[验证记录](../validation/Writer-Explicit-Finish-and-Open.md)。
