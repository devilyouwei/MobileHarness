# 本地语音闭环

## 数据与权限

麦克风 → PlatformKit StreamingMonoPCMResampler（16 kHz 单声道 Float32）→ Gateway VoiceActivitySegmenter（抽象 VAD/Silero 概率分段）→ InputGateway → SpeechRecognitionCapability → final 文本 → AssistantAgent 分句 → OutputGateway → Speech.speak / UI.print。Speech.speak 通过 ModelKit 的 SpeechSynthesisCapability（Apple TTS）把文本加工为 PCM，再通过 App 注入的 PlatformKit 播放服务输出到扬声器并等待实际播放结束；UI.print 追加字幕，两模块可并行。

AppContainer 是具体实现的装配入口；Gateway 与 Agent 不导入具体模型。录音前检查可用性并校验、加载权重，然后只申请麦克风权限；不申请 Apple Speech 识别授权，不联网识别或自动回退。音频仅在内存处理，不保存用户录音。首次加载较慢时 UI 显示加载状态。

分段策略：256 ms 前导缓存、至少 96 ms 连续语音、停顿约 800 ms 确认结束。句内短暂停顿完整保留；确认句尾后只保留约 192 ms 尾音。VAD 会话按 512 点给出概率，采样位置连续；结束输入时保留分段器中不足一帧的原始 PCM，不把补零作为用户录音。

VoiceSegment 区分 silence、maximumDuration、inputFinished。达到约 12 秒仅封装模型输入分段，不代表用户说完；保持 VAD 状态并继续收音。LiveSpeechInput actor 在确认起音后通过 InputGateway.openSpeechStream 持续发送 PCM，并消费 capability 的 partial/final。预览按 segmentID 和 revision 更新，旧版本不能覆盖新结果；仅在停顿或结束输入后由 App 经 InputGateway.submit 提交合并后的 final 一次。Nemotron 支持录音期间的实时字幕；模拟器仅用于界面调试，ASR 和聊天能力明确不可用。模型分段边界可能影响跨段词语准确率，需长句实录验收。

当前界面点击圆形任意位置开启或关闭语音；关闭、退后台、中断或路由变化立即取消录音和播放，并丢弃未提交内容。底层保留结束并提交 API，当前页面不提供该入口。重新开始前等待旧识别及 VAD 会话释放，generation 阻止旧结果展示或播放。

长句分段推理可与收音并行；确认整轮结束后，在剩余识别、LLM 生成和 TTS 期间暂停接收新语句。不支持抢话或全双工。Assistant 持续接收文本增量，遇常见多语言短句标点就输出该句的 say/print，正常生成结束时补发剩余尾句。两句 say 串行至播放完成，print 可同时继续追加；每句播完不恢复收音。收到 assistant.finished 且该输入所有已接纳动作完成后，等待 350 ms 再继续聆听。

## 页面与动效

纯黑页面仅显示圆环和当前字幕。整个圆形（包含中心）都是开关；加载时旋转并缩放，聆听时冰蓝柱纹由实际麦克风 RMS 驱动，朗读时紫色波纹由 TTS PCM 包络驱动。静音时保持轻微待机纹理。模型预热在首次开启时执行，成功后复用。

新增或修订字幕后缀约 400 ms 淡入，稳定前缀保留；显示最近 320 个字符并自动跟随底部，不改变完整识别文本。Assistant 第一条 print 开始回复字幕，之后同一轮按短句追加；显示可能领先于朗读进度。支持系统“减弱动态效果”、VoiceOver 开关状态和动态字体。没有输入框、设置项或聊天列表。

## 资源限制

采集队列最多 64 帧，每帧 8,192 样本，溢出明确失败；VAD 最多 4,096 帧。连续重采样每次最多 8,192 样本，保持滤波器状态，采样率中途变化报错；不对每个分片补尾或重置。VAD 模型输入单次最多 16,000 点，残留小于 512 点；网关对齐缓存上限 32,000 点，不允许无界等待概率输出。Gateway 每个识别分段最多 13 秒、4.1 MB，识别超时 20 秒（首次加载在录音前完成）；final 单段最多 16 KiB，最多 64 段。模型自身 token、缓存和队列上限见模型 README。

每次 say/print 文本最多 2,000 UTF-8 字节；底层 TTS 使用最多 256 块有界 PCM，单次 say 总量最多 8 MiB，合成上限 30 秒。播放器等待实际播放完成，单块时长加 3 秒超时。ActionExecutor 每模块默认最多 32 个动作（含正在执行项），最多跟踪 64 个运行输入；超限明确失败，不丢弃后续句子继续当作成功。UI 最多保留 200 条内存消息。

当前 LiveSpeechInput 最多 128 个排队事件、64,000 样本（4 秒）排队 PCM，单模型流串行发送；整轮接收预算 60 秒、合并文本最多 64 KiB，结束输入后最多等待 20 秒。超限即明确失败，不丢帧继续。旧批量 VoiceInputSession 已删除；VAD 仅发送流式音频与结束事件，不再保留完整语句副本。队列、时长或文本超限明确失败，不截断后当作成功提交。连续时长按 VAD 帧检查；未确认起音的前导音频仍计入分段接收预算。麦克风回调不等待推理，原有有界采集流溢出仍报错。

批量识别路径的诊断日志记录 session ID、分段序号、结束原因、识别耗时和队列长度；实时路径不记录识别文本或原始音频。识别取消释放当前会话；关闭录音还会等待聊天模型卸载。全局资源压力管理尚未实现。

## 构建与验收

`./scripts/check.sh` 检查协议、网关闭环、VAD 与 16/44.1/48 kHz 重采样；网关测试使用明确的替身。`./scripts/test-audio8.sh` 在 Mac 上执行真实 Audio8 ASR 测试；`./scripts/test-silero.sh` 验证真实 VAD，额外设置 `HARNESS_TEST_NEMOTRON=1` 可验证两模型组合。`./scripts/build-ios.sh` 仅证明模拟器可编译，不能代替手机运行验证。

真机需验证：

1. 首次加载与麦克风授权，拒绝或设备不支持时不开始录音。
2. 断网说“你好”，停顿后仅提交一次最终识别；回复按短句追加字幕，每句仅朗读一次。
3. 连续至少 20 轮，确认播完继续聆听且不识别自身回复。
4. 加载、识别、生成和播放期间分别停止，再次开始时旧结果和排队句子不能出现。
5. 退后台、切换耳机、来电中断后停止，可手动恢复。
6. 验证跨多个模型增量的中英文标点、正常结束时无标点尾句、两句语音无重叠且字幕可继续追加。
7. 记录实际手机型号、首句延迟、峰值内存、热状态与识别质量；当前尚未完成这些验收。

此前 Apple Speech code=300 的调查属于旧系统识别路径，本次切换不证明该系统服务问题已修复。

Silero 阈值是语音概率（默认 0.5），不同于旧版音量阈值。播放/识别期间重置 VAD 和重采样缓存，恢复后从新流状态开始；这不等于声学回声消除。

回归增加：句内停顿和句尾裁剪、长句采样连续性、恰好分段边界后的纯静音、不足一帧的尾音、取消丢弃、队列溢出、单次 Agent 提交和取消后复用网关。

## 本地 Assistant 回复

Assistant 输入最多 4 KiB，历史最多 4 轮/1600 个 Character，单次输出最多 256 tokens/2000 UTF-8 字节和 60 个短句，生成超时 30 秒。该预算同时约束累积文本和分句残片。生成取消或失败不冲刷残片，不提交不完整历史；已经打印或播放的内容不能撤回。错误会停止本轮并显示原因。

关闭圆形会取消会话、清空历史和待执行行为，等待推理资源及音频清理后才允许重启。当前是按完整短句连续合成播放，尚无单句未完成时的增量 TTS、持久记忆、播放中抢话或 LLM 工具调用；中文语义质量、逐句语音衔接与 iPhone 长时资源表现仍需实机验收。
