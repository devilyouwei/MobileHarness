# Zipformer 快速打断配置筛选

## 方法

在 Mac 的 ONNX CPU 环境内，以已有回放集筛选分块、识别阈值、关键词增益、音频步长和起声门限。保留上轮词表和两个官方分块制品，固定尾随 blank 为 0，按相同输入与评分定义比较。给独立的中英文合成语音和未参与筛选的说话人打标签，包含明确口令、前导称呼、否定、转述以及包含口令但随后改义的语句。冻结入选配置后只在留出集复核，不根据留出结果回调阈值。

即时打断的验证门限为 100 ms 命中 p95、明确口令召回至少 80%、误触发率至多 5%。达不到时交付旁路观测配置，实际取消仍走原有 Decision。模型权重与打包持久化路径沿用已有边界。本轮不改 App 执行链路。待后续指令再处理跨项目转换与 Hugging Face 上传。

第一轮留出复核结束后，使用该批样本诊断开头是关键词、后续仍在说话的误触发。在已有 KWS 命中事件上增加一个因果约束，要求事件到达时已收到的音频尾部连续静音，测试 40、80、120、160、200 ms。该约束不等待未来音频，拒绝的候选交给常规 Decision。以第一批留出数据筛选该约束，另冻结第三批新说话人及有明确停顿的样本作最终复核。含后续语句的正例用于正确性统计。100 ms 与命中 p95 仅在关键词处于句尾的小组中计算，避免把后续句尾认成口令尾部。

## 分块与阈值

在 M5 Mac 上用 sherpa-onnx 2.0.3 单线程 CPU 跑中英模型，使用 INT8 encoder/joiner 和 FP32 decoder。每组采用四种分块偏移及两次预热。24 条开发音频每个配置回放 96 次，先跑 24 种声学设置，再针对首次命中比较四种相对于起声时间的判定，共 96 个组合。两个发布分块的步进为 160／320 ms，当前 checkpoint 的最大下采样因子为 8，低于 8 的分块需要另行验证导出或架构。见[冻结 ONNX 基线](Zipformer-Apple-ONNX-Baseline-2026-11-25.md)与[开发原始结果](../../experiments/decision/results/zipformer-interrupt-development-2026-11-25.json)。

开发集上，短分块 .45 阈值和 200 ms 词首门限命中 23/32、误打断 0/64、p95 380 ms。长分块 .35 阈值和 120 ms 门限命中 27/32、误打断 0/64、p95 500 ms。统计相同的配置优先选择更严格的识别阈值。短长两个配置和原始基线同时在第一批留出集上复核，各跑 192 条。两种词首门限都降低了误触发，但拒绝了所有带称呼或礼貌前缀的正例。句首与停止口令相同、后续才表明为讨论的负例仍频繁命中。留出音频 ZIP 未随仓库分发。见[短分块](../../experiments/decision/results/zipformer-interrupt-holdout-chunk8-2026-11-25.json)、[长分块](../../experiments/decision/results/zipformer-interrupt-holdout-chunk16-2026-11-25.json)、[原始基线](../../experiments/decision/results/zipformer-interrupt-holdout-prior-2026-11-25.json)结果。

## 旁路候选及最终留出复核

以第一批留出集的原始命中为校准，对三套配置叠加六个尾部静音取值（含关闭），比较 18 组。候选优先检查即时打断门限，其余按召回率减两倍误触发率排序。入选组合为 chunk-8、32 ms 输入包、关键词增益 1.0、阈值 .25、blank 参数 0、无词首门限，首次命中时最近 160 ms 需连续静音。静音用 10 ms 帧的 RMS 低于 .006 判定。门限只读取该次命中已经接收的采样，拒绝后把判定留给现有 final ASR Decision。见[校准结果](../../experiments/decision/results/zipformer-interrupt-tail-calibration-2026-11-25.json)和[交接配置](../../experiments/decision/zipformer-interrupt-observer-2026-11-25.json)。

最终用第三批 48 条新声音与文本复核锁定设置，包含先说出口令相同片段、停顿后才补充上下文的负例。每个模型设置仍跑四种偏移。命中 p95 使用句尾口令正确命中的子集，100 ms 达成率涵盖该子集全部 32 个正例。另两个起声门限候选是此前冻结配置，本轮仅作参照。最终留出音频 ZIP 未随仓库分发。见[候选原始输出](../../experiments/decision/results/zipformer-interrupt-confirmation-trace-2026-11-25.json)和[带门限逐条结果](../../experiments/decision/results/zipformer-interrupt-confirmation-2026-11-25.json)。

| 配置 | 正确 / 192 | 明确口令命中 / 64 | 误打断 / 128 | 句尾命中 p95 | 100 ms 内句尾正确命中 / 32 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原始 chunk-8 | 123 | 43 | 48 | 450 ms | 0 |
| chunk-8，词首门限 200 ms | 125 | 18 | 21 | 470 ms | 0 |
| chunk-16，词首门限 120 ms | 124 | 20 | 24 | 440 ms | 0 |
| **chunk-8，尾部静音 160 ms** | **132** | **29** | **25** | **450 ms** | **0** |

尾部静音把误触发从 48 降到 25，同时减少 14 次正确命中，句尾命中 p95 保持 450 ms。25 次误触发中 13 次来自停顿后继续引用的语句，此类音频的口令开头和停顿都可出现在真实打断中。最终四组均未通过即时打断门限。旁路候选用于观测，真实麦克风、AEC、iPhone 和停播动作尚未测量。

三批累计 3,456 次正式 ONNX 模型回放。静音条件比较复用原始命中，未重复计入推理次数。本轮未对候选执行 Core ML 转换或上传。
