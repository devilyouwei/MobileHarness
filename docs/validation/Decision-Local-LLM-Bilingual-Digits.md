# 本地 Core AI Decision 中英文数字提示词对照

复用 2026-11-13 固定的同一批 100 条中英及混说样例。Qwen3 0.6B、MiniCPM5 1.08B、Qwen2.5 1.54B、Qwen3 1.7B 和 Qwen3.5 0.8B 各跑中文与英文提示词。使用上一轮的本地 Core AI runner 与严格完整数字校验。呈现会话状态、最近助手文本、待答问题及来源，保留输入原文。两种提示均先问最新一句应选哪个动作，再列出三个动作的等义定义，最后要求只输出数字。逐条热态预算为 500 ms。

Qwen3.5 0.8B 复用既有对照的固定 revision、Mac INT8 图和同一发布版本的 tokenizer。单 token 图按静态前缀缓存执行。测量与复现证据单独记录，保留 [上一轮输出格式对照](Decision-Local-LLM-Output-Formats.md)。

## 计分与范围

两版使用相同的 JSON 状态字段名与原始值，变化来自问句、定义及系统角色说明。样例只含既有现场状态与最近助手文本，未构造额外历史。输出去掉首尾空白后必须是单个 ASCII 数字且正常遇到结束 token。最多生成 10 token，达到上限或附加解释均计无效。无效计入全部样例分母和应打断样例的漏打断数。使用贪心解码及制品自带模板，模板支持时关闭思考。

Mac M5 / 16 GiB / macOS 27.2.1（26B131）。每个条件预热三条后逐条计时，计入模板渲染、编码、图推理和读出，不含装载与一次性公共前缀。Qwen3.5 0.8B 使用逐 token 预填充，提示词主体位于可变上下文之后，因此本轮只能缓存真正共用的短前缀。500 ms 是用于结果筛选的预算，实验让推理完成以同时观察语义和实际超限量。

## 模型制品

Qwen3 0.6B 使用 Mac INT4，MiniCPM5 1.08B 使用 INT8，Qwen2.5 1.54B Instruct 和 Qwen3 1.7B 使用 INT8。它们与 [输出格式对照](Decision-Local-LLM-Output-Formats.md) 使用同一批缓存制品。新增 Qwen3.5 0.8B 使用固定 revision 的 Mac INT8 k-means 文本图，重新下载后核对发布方 SHA-256，加载使用同一 revision 的 tokenizer 和模型哈希文件。 [0.8B 制品](https://huggingface.co/mlboydaisuke/qwen3.5-0.8B-CoreAI/tree/b98ad07f1ae7c07fb3e5967091600177f48844c2)

## 历史对话与缓冲区格式复测

业务提示固定为四段，依次是历史对话、缓冲区用户输入、引用最新用户输入的三选一问句和三条动作定义。复用已记录完整历史的 28 条二消息样例，缓冲区显示为空，另以合成样例检查有内容的缓冲区。保持原有三条动作定义，历史和 ASR 原文保留原语言。验证 D3 Edge 与 Qwen2.5 1.54B 中英文版本。D3 使用原生 Choice 所需的模板和候选代码，通用 LLM 将四段作为一个 user 消息。比较分组的结果与 Mac 热态延迟。

中文业务提示实例。英文组只翻译标题、问句和动作定义。

```text
【历史对话】
用户："给我设个提醒，时间还没决定。"
助手："明早八点可以吗？"

【缓冲区用户输入】
（空）

根据以上用户历史对话，判断以下最新用户输入：【嗯。】应该：1. 打断；2. 舍弃；3. 进入队列等待下一轮。

动作定义：
1. 打断：助手正在输出或执行，而且用户要求立即停止、纠正当前内容，或明确要求现在切换任务。引用、否定或延后的停止请求不属于打断。
2. 舍弃：已确认的回声、噪声、与助手无关的谈话、无需回应的附和，以及空闲时只说“停”或助手正说话时只说“继续”。
3. 进入队列等待下一轮：有意义的新请求、问题、补充或回答，包括对待答问题的简短回答，以及要求稍后执行的事。
```

D3 的原生模板把前两段放入 `State`，后两段放入 `Question`，模板随后附上 `A: 1 / B: 2 / C: 3` 并读取分类头。Qwen2.5 使用默认聊天模板，业务文本到第三条定义结束，沿用前轮的严格数字校验。业务文本没有额外状态字段或“只输出数字”这类附加指令。补充的 8 条合成用例包含 4 对相同最新转写、不同先前内容的场景，每条缓冲含一条用户输入。它们用于探测上下文分流，未隔离历史与缓冲的单独影响。

| 制品 | 提示 | 空缓冲正确 / 28 | 非空缓冲正确 / 8 | 空缓冲 p95 ms | 非空缓冲 p95 ms |
| --- | --- | ---: | ---: | ---: | ---: |
| D3 Edge | 中文 | 13 | 3 | 46.55 | 46.37 |
| D3 Edge | 英文 | 12 | 5 | 46.33 | 46.47 |
| Qwen2.5 1.54B | 中文 | 0 | 0 | 228.50 | 240.76 |
| Qwen2.5 1.54B | 英文 | 0 | 0 | 212.60 | 204.64 |

D3 两组都没有选过入队。Qwen2.5 中英文共 72 次都未生成单个数字，多数复述完整选项，如 `3. 进入队列等待下一轮`，所以表中 0 表示严格格式下的计分。共 144 次热态推理全部在 500 ms 内。素材与上面的 100 条数字实验不同，分数不能直接相减。App 运行时未改。
