# 历史与原始设计

本目录保存演进经过和旧设计，不定义当前能力、默认值或待办。日期对应原记录；迁移日期只说明文档何时整理。最新范围见 [产品说明](../Product-Scope.md)、[当前架构](../Architecture.md) 和 [未完成需求](../requirements/README.md)。

| 文档 | 职责 |
| --- | --- |
| [Change log](Change-Log.md) | 按日期描述做了什么及原因，验证细节链接到验证记录。 |
| [Documentation history](Documentation-History.md) | 从当前说明中迁出的旧术语、架构叙述与文档审计上下文；不重复持有当前设计。 |
| [代码 README 历史摘录](Code-README-History.md) | 从代码目录 README 迁出的修改经过、旧契约与历史验证摘要；只用于追溯，不定义当前能力或待办。 |
| [Milestone history](Milestone-History.md) | 早期交付阶段、旧路线图和当时的待办；不能直接作为当前路线图。 |
| [原始 Markdown 设计](Tech_Design.md) | 2026-09-23 的历史技术基线，保留原始设想与示例供追溯。 |

原始 Word 设计源 [Technical_Design.docx](../Technical_Design.docx) 按仓库约定保留原路径和内容，不另存副本。

完整交付的需求原文归 [completed](../completed/README.md)，决策归 [adr](../adr/README.md)，实验/构建/设备证据归 [validation](../validation/README.md)。历史叙述可以链接这些来源，不重新定义其结论。

整理混合文档时，保留有独立价值的旧日期、边界与上下文；去除完全重复的叙述段落和入口摘要，指向对应的原始记录。出现同名概念但版本、设备、失败或测量不同的记录，不按重复删除。
